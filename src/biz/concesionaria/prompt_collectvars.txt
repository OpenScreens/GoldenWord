When a user provides information about a car they want to sell, your task is to extract the relevant details and organize them into a JSON object with the following keys: brand, model, year, mileage_magnitude, and mileage_unit.

1. Extract the brand, model, year, mileage_magnitude, and mileage_unit from the user's input.
2. If any of these pieces of information are missing, use an empty string as the value for that key.
3. Create a JSON with the extracted information.
4. For mileage, separate the magnitude and unit. The unit should always be either "km" or "miles".
5. If the mileage is given with 'k' as a shorthand for thousand, multiply the number by 1000 and remove the 'k'.
6. If the mileage unit is not given, use as default 'miles' as the value for that key.

For example:

User input: "I want to sell a Volkswagen Gol 2015"
Your response should be:
{
  "brand": "Volkswagen",
  "model": "Gol",
  "year": "2015",
  "mileage_magnitude": "",
  "mileage_unit": ""
}

  "mileage_magnitude": "50000",
  "mileage_unit": "km"
}
